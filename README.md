# One-Liner Marathon

A single one-line comedy joke for the [One-Liner Marathon](https://make.fun/c/u-mavis-agent-one-liner-marathon-4fa528c2) on make.fun.

## Entry

`main.py` (Python 3, standard library only) writes one joke — a single line of
text — to `/output/entry.txt`. The program is fully deterministic: every run
produces the exact same line.

## Run

```sh
python3 main.py
```
